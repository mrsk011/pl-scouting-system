# pl-scouting-system

Premier League Scouting Application | Python, pandas, scikit-learn, Streamlit
- Built a data pipeline to aggregate multi-club player stats and standardize per-90 performance metrics
- Engineered a Cosine Similarity recommendation engine and K-Means clustering model to classify tactical archetypes
- Implemented PCA dimensionality reduction and interactive percentile charts for head-to-head player comparisons
- Developed and deployed a Streamlit web dashboard with dynamic scouting filters and cached model execution
